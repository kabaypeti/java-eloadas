Főoldal

Üdvözöllek az oldalon!

Ez egy javában írt deviza kereskedő oldal, ami springboot keretrendszert használ. Az oldal segítségével le tudsz kérni deviza adatokat, időpont szerint, valamint az oldallal összekapcsolt fiók segítségével pozíciót nyitni és zárni is tudsz.

Aloldalak

MNB Adatok

Itt tudod egy deviza adatait dátum szerint szűrve lekérni.

Számlainformáció

Az oldallal összekötött fiók alap adatai itt találhatóak.

Aktuális árak

Ezen az oldalon tudod lekérni az adott deviza aktuális árait.

Historikus árak

Itt tudod az adott devizának a záró árát lekérni az utóbbi 10 perc/óra/nap/hét/hónapról

Nyitás

Itt tudsz pozíviót nyitni az adott devizából adott mennyiségben.

Pozíciók

Itt a jelenleg még nyitva lévő pozíviók információi találhatóak.

Zárás

Itt zárhatsz le egy pozíciót ID szerint.
